⏰ Relógio Digital | HTML + CSS + JavaScript
Este projeto é um Relógio Digital em tempo real, desenvolvido para praticar manipulação do DOM, uso do objeto Date e atualização automática com setInterval().

O relógio exibe horas, minutos e segundos, atualizando a cada segundo, com um design moderno usando CSS.

🚀 Funcionalidades
✔ Exibe horas, minutos e segundos

✔ Atualização automática em tempo real

✔ Interface moderna com efeito glassmorphism

✔ Totalmente responsivo

✔ Código simples e organizado
